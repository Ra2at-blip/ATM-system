# 🏦 ATM Banking System (Python)

A simple console-based ATM Banking System developed using Python.
This project simulates basic banking operations such as account creation, deposit, withdrawal, and balance checking.

## 📌 Features

* ✅ Create a new bank account
* 💰 Deposit money
* 💸 Withdraw money
* 🧾 Optional withdrawal voucher printing
* 📊 Check account balance
* 🔐 Random 6-digit account number generation
* 🖥️ Menu-driven interactive system

## 🛠️ Technologies Used

* Python 3
* OOP (Object-Oriented Programming)
* `random` module
* Python 3.10+ `match-case` statement

## 📖 Program Workflow

1. User creates an account.
2. System generates a random 6-digit account number.
3. User can:

   * Deposit money
   * Withdraw money (with balance validation)
   * Check balance
4. Program runs in a loop until user selects Exit.
